SIMD-Aware Cayley-Dickson Algebras

KYOSU is a C++20 library for complex numbers, quaternions, octonions, and the Cayley-Dickson algebras over \(\mathbb{R}\) of any dimension. It extends the real functions to all of them, the transcendentals as well as the Legendre polynomials and the elliptic integrals, and every function accepts a scalar and a SIMD register alike. The complex numbers are the two-dimensional case, with the same vectorization as the other algebras.

Features

Any dimension

About two hundred functions take a real or a hypercomplex argument under one name.

#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
using kyosu::sqr;
// The same name for every dimension of the argument.
std::cout << "complex: " << sqr(kyosu::complex_t<double>(1., 2.)) << "\n";
std::cout << "quaternion: " << sqr(kyosu::quaternion_t<double>(1., 2., 3., 4.)) << "\n";
std::cout << "octonion: " << sqr(kyosu::octonion_t<double>(1., 2., 3., 4., 5., 6., 7., 8.)) << "\n";
}

SIMD registers

A function takes one value or an eve::wide of values under the same name.

#include <eve/wide.hpp>
#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
eve::wide<double, 2> re(1., 3.), im(2., 4.);
auto c = kyosu::complex(1., 2.);
auto w = kyosu::complex(re, im);
// The same call, on one value or on a register of them.
std::cout << "scalar: " << c << " -> " << kyosu::sqr(c) << "\n";
std::cout << "SIMD: " << w << " -> " << kyosu::sqr(w) << "\n";
}

Accuracy and special values

By default a function handles the infinities and the NaN at the edges of its domain. The option kyosu::raw skips those checks and uses faster, less accurate formulas.

#include <iostream>
#include <limits>
#include <kyosu/kyosu.hpp>
int main()
{
auto inf = std::numeric_limits<double>::infinity();
auto nan = std::numeric_limits<double>::quiet_NaN();
auto z = kyosu::complex(inf, nan);
// By default, the modulus of a value with an infinite component is infinite, even with a NaN
// component. raw skips that check and returns NaN.
std::cout << "abs = " << kyosu::abs(z) << "\n";
std::cout << "abs[raw] = " << kyosu::abs[kyosu::raw](z) << "\n";
}

Half-turns

With the option kyosu::radpi, an angle is read and returned as a multiple of \(\pi\) instead of radians.

#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
auto z = kyosu::complex_t<double>(-1., 0.);
// The argument of -1 is a half-turn, in radians or in multiples of pi.
std::cout << "arg = " << kyosu::arg(z) << "\n";
std::cout << "arg[radpi] = " << kyosu::arg[kyosu::radpi](z) << "\n";
}

Real results

A real argument outside the real domain of a function gives a complex result. With the option kyosu::real_only, the function calls its EVE counterpart, which returns NaN.

#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
// -1 is outside the real domain of sqrt, so the answer is complex.
std::cout << "sqrt(-1.0) = " << kyosu::sqrt(-1.0) << "\n";
// real_only calls eve::sqrt instead, which returns NaN.
std::cout << "sqrt[real_only](-1.0) = " << kyosu::sqrt[kyosu::real_only](-1.0) << "\n";
}

Algebras

KYOSU implements the following algebras, with components in IEEE float or double:

  • complex numbers,
  • quaternions,
  • octonions,
  • algebras of any dimension \(2^n\).

An operation on operands of different dimensions returns the largest dimension, the missing components being zero. From the quaternions on, the product does not commute, so kyosu::ldiv exists beside /. The constants kyosu::i, kyosu::mi, kyosu::j, and kyosu::k are defined, and kyosu::muli and kyosu::mulmi multiply by \(i\) and \(-i\).

#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
using q_t = kyosu::quaternion_t<double>;
auto c = kyosu::complex_t<double>(1., 2.);
auto q = q_t(1., 2., 3., 4.);
auto o = kyosu::octonion_t<double>(1., 2., 3., 4., 5., 6., 7., 8.);
// Operands of different dimensions give a result of the larger one.
std::cout << "c + q = " << c + q << "\n";
std::cout << "q * o = " << q * o << "\n";
// The constants follow the algebra, whose product does not commute.
auto i = kyosu::i(kyosu::as<q_t>());
auto j = kyosu::j(kyosu::as<q_t>());
std::cout << "i * j = " << i * j << "\n";
std::cout << "j * i = " << j * i << "\n";
// Hence a left division beside the right one.
std::cout << "q / c = " << q / c << "\n";
std::cout << "ldiv(c, q) = " << kyosu::ldiv(c, q) << "\n";
}

Constructors

A value is built from a parametrization by kyosu::from_euler, kyosu::from_polar, kyosu::from_spherical, kyosu::from_cylindrical, or kyosu::from_angle_axis.

#include <iostream>
#include <kyosu/kyosu.hpp>
int main()
{
// A rotation given as three Euler angles, in the order they are applied.
using kyosu::X_;
using kyosu::Y_;
using kyosu::Z_;
auto q = kyosu::from_euler(eve::pio_3(eve::as(0.0)), eve::pio_4(eve::as(0.0)),
eve::pio_6(eve::as(0.0)), Z_, Y_, X_);
std::cout << "from_euler = " << q << "\n";
// Or as a modulus and an argument.
std::cout << "from_polar = " << kyosu::from_polar(2., eve::pio_4(eve::as(0.0))) << "\n";
}
